# 方法误用清单（本 Skill 主动规避）

1. 三组及以上塞进两样本 t 检验 → 用 ANOVA/Welch ANOVA/Kruskal + 事后校正。
2. 缺失值当 0 或整行静默删除 → 缺失仅排除该变量该次计算，n 逐组报告。
3. 重复记录不去重 → 守卫式整行去重（keep first），删除数写入 cleaning。
4. 正态性、方差齐性未检验直接参数检验 → 每结局先检验、给 p、给选择理由。
5. 只有 p 值没有效应量与 CI → 每个主结论绑定效应量 + 95% CI。
6. p=0.04 写成“证明有效” → 统一措辞“在 α=… 水平下差异具有统计学意义”。
7. 多重比较不校正 → Holm 家族校正，校正后 p 下结论。
8. 非正态小样本套 t 检验 → n<8 或非正态一律秩方法主检验。
9. 配对数据当独立样本 → 任务关键词触发配对设计（差值检验）。
10. 观测数据写因果 → 全部结论标注“关联，不推断因果”。
11. 异常值静默剔除 → 不剔除；秩方法与稳健效应量天然稳健，必要时在
    limitations 说明。
12. 换包版本结果漂移 → 纯标准库实现 + 固定种子 + 输入哈希，跨机器可复算。

# 置信区间方法

| 估计量 | 方法 | 说明 |
|---|---|---|
| 均值差（两组） | Welch 解析 CI | t 分位 × Welch SE；与 Welch t 检验结论一致 |
| Cohen's d | 百分位 bootstrap，B=2000，seed=20240501 | 固定种子，可复算 |
| 中位数差 | Hodges-Lehmann 点估计 + 正态近似分位区间 | 区间仅近似，报告中标注 |
| 回归斜率 | OLS 解析 CI（t 分位） | 经典公式 |
| Pearson r | Fisher z 变换区间 | n≥4 有效 |

解读规范：CI 是估计量的不确定性范围，不是个体取值范围；CI 跨 0（差值类）
或与检验结论不一致时以检验为准并在 limitations 说明；报告中必须同时出现
点估计、区间宽度与覆盖概率（95%）。

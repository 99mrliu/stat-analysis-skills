# 校准语言决策表（wording-rules）

本表是 report.py 措辞引擎的规则说明，也是 agent 人工微调措辞时的对照标准。所有面向用户的句子使用书面中文（本研究/该分析；禁止 我/你），全角标点（，。；：（）「」），数字用半角。

## 1. 显著性句式（必填）

- 显著：`在 α={alpha} 水平下，{分组变量}各组间{结果变量}的差异具有统计学意义（{方法}，p={p}）。`
- 不显著：`在 α={alpha} 水平下，{分组变量}各组间{结果变量}的差异不具有统计学意义（{方法}，p={p}）；证据不足以支持「{结果变量}随{分组变量}不同而存在差异」的结论。`
- 动词分级：不显著 → 「证据不足以支持」；中等效应 → 「提示」；大效应 → 「表明」。禁止「证明」。

## 2. 效应量量级（按效应量家族阈值）

| 家族 | 小/中/大阈值 |
|---|---|
| Cohen's d / Hedges' g | 0.2 / 0.5 / 0.8 |
| η² / ε² / ω² | 0.01 / 0.06 / 0.14 |
| r / ρ / rank-biserial | 0.1 / 0.3 / 0.5 |

判级后接不同句式：
- 显著 + 大效应：`效应量 {name}={value}，按常用阈值属于大效应，表明该差异可能具有实际意义；其实际重要性仍需结合领域阈值判断。`
- 显著 + 中等效应：`…属于中等效应，提示该差异可能具有实际意义；是否达到实际重要需结合领域阈值 Δ 判断。`
- 显著 + 小效应：`…属于小效应；统计显著并不等同于实际重要，该差异的实际意义有限。`
- 不显著 + 最小组 n<30：`阴性结果可能受样本量限制；不宜将「不具有统计学意义」解读为「不存在差异」。`

## 3. 实际意义句式（必填，二选一）

- Δ 已知（findings.practically_important_difference）：`相对于实际重要差异阈值 Δ={Δ}，观察到的效应{达到或超过 / 未达到}该阈值，…实际意义…。`
- Δ 未知：`任务未给出实际重要差异 Δ；统计显著性与实际意义必须分开表述，实际意义需结合领域标准另行判断。`

## 4. 置信区间含义句（必填）

`{效应量}的 95% 置信区间为 [{lo}, {hi}]；该区间刻画估计量的不确定性，并非个体取值的范围。`

## 5. 多重比较句式

`经 {method} 校正后，调整后 p={adjusted_p}，结论{保持不变 / 差异不再具有统计学意义，未校正结果不应单独作为结论依据}。`

## 6. 局限句式（自动组装）

来源：findings.limitations + 自动检测（最小组 n<30 → 检验效能有限；上游提示非正态 → 结论依赖秩方法；多组且未校正 → I 类错误率膨胀；观察性设计 → 不能推断因果）。

## 7. claim_strength 标签

| 情形 | 标签 |
|---|---|
| 不显著 | tentative |
| 显著 + 小/中等效应 | moderate |
| 显著 + 大效应 | strong |
| 无检验结果 | not_applicable |

## 8. 示例句（每个含 claim_strength）

1. 不显著 + 小样本（tentative）：`在 α=0.05 水平下，处理组与对照组的差异不具有统计学意义（Welch t 检验，p=0.083）；证据不足以支持两组存在差异的结论。阴性结果可能受样本量限制（最小组 n=12）；不宜将「不具有统计学意义」解读为「不存在差异」。`
2. 显著 + 微小效应（moderate）：`在 α=0.05 水平下，两组的差异具有统计学意义（Welch t 检验，p=0.021）。效应量 Cohen's d=0.18，按常用阈值属于小效应；统计显著并不等同于实际重要，该差异的实际意义有限。`
3. 显著 + 大效应（strong）：`在 α=0.05 水平下，三组的差异具有统计学意义（Kruskal-Wallis H，p=4.8e-29）。效应量 ε²=0.87，按常用阈值属于大效应，表明该差异可能具有实际意义；其实际重要性仍需结合领域阈值判断。`
4. 非正态用秩检验（strong）：`由于 Shapiro-Wilk 检验提示正态性假设不满足，该分析采用 Kruskal-Wallis 秩检验而非方差分析；结论依赖对分布稳健的秩方法。`
5. 多重比较校正后不再显著（tentative）：`经 Dunn-Bonferroni 校正后，调整后 p=0.048；差异不再具有统计学意义，未校正结果不应单独作为结论依据。`

## 9. 禁用语清单（出现即视为不合格）

- 「证明」「证实了」「说明有效」；
- 「显著，所以重要」（把统计显著直接等同于实际意义）；
- 「相关，因此是因果」（相关即因果）；
- 将 p=0.049 与 p=0.051 描述为结论不同（p 值不连续，应整体看证据强弱）；
- 「差异不存在」（阴性结果只能说证据不足）；
- 第一/第二人称（我/你/我们）。

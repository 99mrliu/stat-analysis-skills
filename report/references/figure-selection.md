# 图形选择规则（figure-selection）

report.py 按以下优先级选择图一（fig1）；每个选择都在 figures.md 中写明理由与每组样本量。

## 决策规则（按优先级）

1. **配对设计**（findings.paired == true）→ **斜率图（slope graph）**：组均值连线，呈现组内变化方向。
2. **单组**（只有一组数据）→ **直方图（histogram）**：回答分布形态问题。
3. **上游标记非正态/偏态**（assumptions.normality ∈ {false, non_normal, violated, 非正态} 或 skew 标记）→ **ECDF 叠加图**：避免箱线图掩盖双峰/偏态等分布形态。
4. **任务焦点为均值且每组 n≥30**（assumptions.focus == "means"）→ **条形图 + 95% CI**，并附 fig2 箱线图作为分布背景（防止条形图掩盖分布）。
5. **默认** → **分组箱线图 + 抖动散点（boxplot + jitter）**：每组 n≤500 时叠加确定性偏移的散点；n>500 时仅箱线图（散点过密失去信息量）。

## 图形规范

- 轴标签必须含变量名；单位以原始数据口径为准并写入 figures.md 图注；图注必须含每组 n。
- 抖动为确定性等距偏移（无随机数），保证可复现。
- 中文字体不可用时自动回退英文标签，不崩溃。
- matplotlib 不可用时：不生成位图，figures.md 写明「应画什么 + 底层数值表」，交付不中断。

## 反模式（禁忌）

- **饼图**：人眼对面积/角度判断差，组间比较一律不用饼图；
- **双 y 轴**：容易制造虚假相关印象，禁止；
- **截断 y 轴**：条形图 y 轴必须从 0 开始；箱线图可自动范围但须在图注说明；
- **无散点的纯均值条形图**（"dynamite plot"）单独使用：必须搭配分布背景（fig2）；
- **3D 效果、渐变填充**：无信息增量，禁止；
- ** violin 图**：当上游同时提供密度估计依据且每组 n≥50 时可作为箱线图的替代，否则默认箱线图（本组件当前不自动画 violin，需人工指定时由 agent 用 matplotlib 补画并更新 figures.md）。

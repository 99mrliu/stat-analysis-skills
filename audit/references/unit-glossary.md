# 单位与量纲速查（unit glossary）

## 列名单位词表（本 Skill 扫描）

`mg, μg, ug, mcg, g, kg, ml, l, cm, mm, m, MPa, Pa, day, days, 天, %`（长短语优先：`mg` 命中后不再记 `g`；`MPa` 命中后不再记 `Pa`/`m`）。
词边界匹配，避免 "image" 误命中 "mg"。

## 量级换算因子（scale mismatch 候选）

| 因子 | 典型场景 |
|---|---|
| 10³ | g↔kg、mg↔g、ml↔l、mm↔m |
| 10⁶ | μg↔g、mm³↔m³ |
| 12 | 英寸↔英尺、月↔年 |
| 2.54 | 英寸↔厘米 |

判定：两源同列逐值比（db/csv）的中位数落在某因子 ±5% 内且配对数 ≥10 → 记 scale suspect（仅标记）。

## TEXT vs REAL（SQLite affinity 与导出陷阱）

- SQLite 列声明 `TEXT` 但 ≥95% 值可解析为数值 → **numeric-in-text 陷阱**：比较/排序按字符串进行（"9">"10"），聚合函数行为不同；读入分析前必须 coercion。
- 详见 `sqlite-audit.md` 的 affinity 映射表。

## 常见导出陷阱

- **千分位**：`"1,030"`（带引号才能进 CSV 单元格）；正则 `^-?\d{1,3}(,\d{3})+(\.\d+)?$` 识别后去逗号。
- **百分数两种口径**：0–1（比例）vs 0–100（百分数）。观测 max ≤1 且列名含 percent → 提示可能为 0–1 口径；>100 的值在 0–100 口径下为不可能值。
- **值内单位后缀**：`"12 mg"`、`"45%"`：拆出数值 + 单位记入 unit_hint_values；同列 ≥50% 单元格带同一后缀时列为该列单位提示。
- **全角字符**：全角数字/百分号经 NFKC 归一化后参与解析。
- **混合精度**：同一列整数与小数混排属正常；整数列被导出成 `28.0` 时注意与 `28` 的跨源比较容差（脚本用 1e-9 相对容差）。

## 原则

单位问题**只提示、只记录、绝不自动换算**；换算属于分析口径决策，必须留痕于清洗账本。

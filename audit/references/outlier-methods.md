# 异常值方法（outlier methods）

## 三种标记口径（本 Skill 全部计算，互相印证）

1. **IQR 栅栏**：Q1/Q3 用线性插值分位数；温和栅栏 = Q1−1.5×IQR ~ Q3+1.5×IQR；极端栅栏 = 3×IQR。对偏态稳健、无需分布假设。
2. **修正 z 分数（MAD）**：z* = 0.6745×(x−median)/MAD，|z*|>3.5 标记。MAD=median(|x−median|)。对均值/标准差被离群值拉爆的情形稳健。注意：当 >50% 取值相同时 MAD=0，此时跳过（脚本已防护）。
3. **分组内 IQR**：当存在 2–10 个唯一值的分组列（如物种、龄期组、批次）时，在每组内重算栅栏。全局正常的值可能是组内异常（如某龄期组内的超常强度）。

## 不可能值检查（impossible values）

- 列名匹配 age/length/width/strength/weight/amount/percent/浓度/含量/强度/龄期/重量 等 → 负值标记。
- 百分比口径列（列名含 percent/pct/%/率，或值带 % 后缀）→ >100 标记。
- 合理性区间表（如水 100–300 kg/m³、混凝土强度 0–120 MPa、龄期 1–365 天）只**提示**，绝不硬拒绝。
- 以上全部只 flag，绝不自动修正——"不可能"也可能是单位口径错误（见 unit-glossary.md）。

## 绝不静默删除规则

- 默认动作一律 `flag`；只有 agent 经 `decide` 显式给出 `drop` 并写明理由，清洗表才剔除。
- 删除前必须能在账本中回答：哪几行、什么条件、谁决定的、理由是什么。

## 处置词汇（disposition vocabulary）

- `keep`：确认该值为真实观测，参与分析（撤销 flag 的语义）。
- `flag`：保留但在报告中标注，下游可做含/不含敏感性分析（默认）。
- `drop`：从 cleaned_table.csv 剔除（行索引记入账本）。

## 报告要求

每列给出 Q1/Q3/IQR/median/MAD、温和/极端/MAD 命中数、行索引与取值；分组口径注明所用分组列。
